Municipal Quotation Builder - Self-Contained Windows Package

Recommended: use Municipal_Quotation_Builder_Setup.exe.

For portable use, extract the entire ZIP to a folder before running
MunicipalQuotationBuilder.exe. Do not run the EXE from inside the ZIP and do
not copy the EXE by itself. The data folder and every DLL must remain beside it.

Supported systems: 64-bit Windows 10 and Windows 11.
